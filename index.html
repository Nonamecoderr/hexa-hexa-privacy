Политика конфиденциальности

Приложение «HEXA HEXA» (Android, RuStore) · Дата публикации: 25 октября 2026 г.

Настоящая политика описывает, какие данные обрабатываются при использовании игры «HEXA HEXA», в каких целях и каким образом вы можете управлять этими данными.

1. Оператор персональных данных

Сибирев Борис Сергеевич (физическое лицо), публичное имя разработчика — burakkuberi.
Контакт по вопросам обработки данных и поддержки: burakkuberi@proton.me.

2. Какие данные обрабатываются

Само приложение не собирает и не передаёт разработчику никаких персональных данных. Игровой прогресс, рекорд и настройки хранятся локально на вашем устройстве (localStorage WebView) и никуда не отправляются. Регистрация и учётная запись не требуются.

Для показа рекламы в приложение встроен Yandex Mobile Ads SDK (ООО «Яндекс», Россия). SDK может автоматически обрабатывать: рекламный идентификатор устройства (Ad ID), сведения об устройстве и ОС, IP-адрес, данные о показах и взаимодействии с рекламой — для подбора и показа объявлений, измерения их эффективности и предотвращения мошенничества. Обработка этих данных выполняется Яндексом в соответствии с его собственной Политикой конфиденциальности.

3. Цели обработки

  • показ рекламы и монетизация бесплатного приложения (законный интерес разработчика);
  • техническая работоспособность игры — исключительно локально на устройстве.

4. Хранение и удаление

Локальные данные игры хранятся на устройстве до удаления приложения — удаление приложения полностью удаляет эти данные. Сроки хранения данных, обрабатываемых Yandex Mobile Ads SDK, определяются политикой Яндекса.

5. Передача третьим лицам

Разработчик не передаёт никакие данные третьим лицам. Единственный внешний обработчик — Yandex Mobile Ads SDK (см. п. 2).

6. Ваши права

Вы можете: удалить приложение (локальные данные будут удалены); ограничить рекламную персонализацию в настройках Android («Реклама» → сброс или отключение рекламного идентификатора); обратиться с любым запросом по адресу burakkuberi@proton.me.

7. Дети

Приложение имеет возрастную маркировку 12+ и не предназначено для детской аудитории. Заведомый сбор данных детей не осуществляется.

8. Изменения политики

Актуальная версия политики всегда доступна на этой странице и по ссылке внутри приложения (Настройки → «Политика конфиденциальности»). Существенные изменения будут отражаться обновлением даты в начале документа.
